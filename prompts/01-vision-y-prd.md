## Prompt 1c — PRD

```
Actúa como un Product Manager senior. Necesito un PRD para un sistema de recruitflow.
El público objetivo son empresas que se dedican a selección de personal para determinados
puestos que les solicitan los clientes y que valoran la velocidad y los skills matched de
las personas del sistema con los necesarios por el cliente para realizar determinadas tareas.
Genera un PRD completo incluyendo: problema a resolver, objetivos medibles, user stories
principales, requisitos funcionales y no funcionales, y criterios de éxito.
```
